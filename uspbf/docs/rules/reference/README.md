# Reference rulesets (non-WPA/WPBA or TBD)

## Texas Express

Texas Express (9-ball variant) is not bundled in this repository. When USPBF adopts it:

1. Obtain the **current official** rules PDF or published URL from the sanctioning body or tour.
2. Save the PDF under `docs/rules/reference/` (or link externally from WordPress).
3. Note in WordPress which USPBF divisions use Texas Express.

## Other references

- BCA / APA bar rules: link or PDF as needed for amateur events; keep **reference** vs **USPBF official** clear on the site.
