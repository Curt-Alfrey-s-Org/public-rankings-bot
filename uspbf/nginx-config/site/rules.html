Rules & disciplines

USPBF starts from WPA and WPBA published rules. Variants (for example Texas Express 9-ball) will be labeled clearly when adopted for sanctioned events.

Official sources

  • WPA (World Pool Association) — Rules & regulations (PDFs)
  • WPBA — WPBA rules

Games we cover

  • 9-Ball — WPA / WPBA baselines; express formats documented per event.
  • 8-Ball — WPA international 8-ball and related specifications.
  • 10-Ball — WPA standard.
  • One-pocket — WPA where applicable; house/culture variants noted per venue.
  • Straight pool — WPA.
  • Banks — As published for WPA-sanctioned or USPBF-adopted sets.
  • Scotch doubles (mixed) — Men/women teams at USPBF-sanctioned co-ed team events.
  • Artistic pool — WPA artistic / APD references.
  • Heyball — WPA Heyball rules PDF via wpapool.com/rules.
  • Pyramid — WPA pyramid rules PDF via WPA rules page.

Reference copies of some PDFs also appear in this project under docs/rules/ (see docs/rules/README.md). For official citations, use the federation’s current published rules.
