Rankings Bot — What talks to what

Use this page to see the request flow and diagnose why the site or bot isn’t updating. Open docs/diagrams/architecture.html in a browser (no server needed).

Standard: One reverse proxy (Nginx), one backend (host API :8003). Two proxies or two runtimes cause problems — see PRODUCTION_DEPLOYMENT.md.

Current flow (Feb 2026) — Tunnel → Nginx → API (Docker)

How the live site runs now: Cloudflare Tunnel (cf-probilliards) routes to probilliards-nginx, which proxies to rankings-bot-api (Docker). The API container serves both the React app (baked-in frontend/dist) and /api. If you don’t see UI updates, rebuild the frontend, rebuild the API image, and restart the rankings-bot-api container (see checklist below).

Why you don’t see updates on screen

Deploy so UI changes show (Option B: frontend mounted)

The live site is served from the rankings-bot-api container. Frontend is mounted from the host (frontend/dist), not baked into the image. So after changing the website:

  • 1. Build frontend: cd frontend && npm run build
  • 2. Restart the API container: sudo docker restart rankings-bot-api

No image rebuild for website-only edits. If you change API/backend code, then rebuild the image and recreate the container. See docs/DOCKER_BASE_AND_SMALL_EDITS.md.

Standard: Nginx → host API

One proxy (Nginx), one backend (API on host :8003). The API serves frontend/dist from disk. No Docker in the path. Deploy: ./scripts/deploy_website.sh --reload-nginx.

Not the standard. A reverse proxy routes / to the frontend container and /api to the API container. Frontend serves files baked into its image.

Quick diagnose checklist

  • Site not updating (hard refresh / incognito didn’t help)
    → Standard: run ./scripts/deploy_website.sh --reload-nginx. If you use Docker: rebuild frontend image and restart rankings-bot-frontend. See REQUEST_FLOW_AND_ARCHITECTURE.md.
  • Which setup am I on?
    → Nginx proxies to 127.0.0.1:8003 = standard (host API). Docker Compose on tunnel_network = alternative (containers). See PRODUCTION_DEPLOYMENT.md.
  • API errors / bot not responding
    → Check API logs; see DEPLOY_UPDATES.md and TROUBLESHOOT_BOT_NOT_VISIBLE.md.
