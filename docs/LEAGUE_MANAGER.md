# League Manager — Reference & Roadmap

**Source:** [leagues.digitalpool.com](https://leagues.digitalpool.com/)  
**Purpose:** Reference for future Rankings Bot league management features

---

## Overview

External Pool League Manager provides tools for running pool leagues. Use this doc as a reference when implementing league features for the Rankings Bot.

---

## Key Features (to analyze)

| Feature | Description |
|---------|-------------|
| Smart Scheduling | Generate round-robin schedules automatically |
| Custom Scoresheets | Customize scoresheets for league format |
| Auto Handicaps | Automate handicaps based on player averages |
| Real-Time Stats | Automatically update team and player statistics |
| Player Portal | Live score entry support |
| Singles Support | Full support for singles league formats |
| Skill Adjustments | Automated skill level adjustments |
| Fargo-Rate Integration | Automatically pull official Fargo-Rates |

### Find My League

### League Operators
Create organizations, leagues, and sessions; manage schedules and handicaps.
