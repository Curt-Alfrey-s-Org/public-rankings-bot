## 🔍 General Search Techniques

### Technique 1: Direct Organization Website Search
```
Steps:
1. Visit official website (BCA.com, EPBF.info, etc.)
2. Look for "Player Directory", "Members", "Ratings", etc.
3. Search by player name
4. Note license number from profile
```

### Technique 2: Tournament Archive Search
```
Steps:
1. Go to tournament site (External Pool, previous WPBA tournaments)
2. Look for tournament brackets
3. Bracket often shows BCA # or license info after name
4. Record the format and number
```

### Technique 3: Social Media + Web Search
```
Steps:
1. Search: "[Player Name] BCA license"
2. Search: "[Player Name] pool license number"
3. Search: "[Player Name] WPBA professional"
4. Look for LinkedIn, Facebook profiles
5. Extract license info from bios or descriptions
```

### Technique 4: Cross-Reference Existing Players
```
Steps:
1. Use WPBA rankings page (if available)
2. Look for biographical data
3. Some profiles may link to license info
4. Check tournament websites where they competed
```
