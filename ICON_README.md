# Icon Information

The Rankings Bot includes a professional 3D 8-ball rack icon for the desktop launcher.

## Default Icon

The included icon features:
- **3D 8-ball rack** with 15 billiard balls arranged in a triangle
- **Green felt table** background with gradient for depth
- **Realistic billiard balls** with 3D shading and highlights
- **Black 8-ball** prominently displayed in the center of the rack
- **Wooden rack frame** outline for authentic pool table appearance

Available formats:
- `icon.png` - 256x256 high-quality PNG with transparency
- `icon-512.png` - 512x512 high-resolution PNG for larger displays
- `icon.svg` - Scalable vector version with radial gradients

## Customizing the Icon

You can replace the icon with your own:

1. Create or find a suitable icon image (recommended: 256x256 pixels or larger)
2. Save it as `icon.svg` (vector) or `icon.png` (raster) in the project root directory
3. Update `rankings-bot.desktop` to reference your icon file
4. Re-run the installer: `./scripts/install_desktop_launcher.sh`

## Icon Suggestions

- Pool/billiards related imagery (cue ball, pool table, cue stick)
- Trophy or ranking symbol
- Simple text badge with "WPBA/WPA"

## Icon Resources

You can use free icon resources like:
- https://www.flaticon.com/ (search for "billiards" or "pool")
- https://icons8.com/ (search for "pool" or "ranking")
